\doxysubsection{Detailed Description}
Application entry point for the Football Scoreboard. 

Initializes and launches a modular graphical scoreboard system for managing football match events. Creates two synchronized main windows\+: Control (operator) and Scoreboard (audience display), linked via Qt signals/slots.

Features\+:
\begin{DoxyItemize}
\item Real-\/time goal tracking with timestamps and player attribution.
\item Two-\/half timer management (00\+:00–45\+:00, 45\+:00–90\+:00).
\item Own goal and undo support.
\item CSV import for player lists (UTF-\/8, supports umlauts).
\item Team emblems and fullscreen toggle.
\item Match state machine with window toggling.
\end{DoxyItemize}
