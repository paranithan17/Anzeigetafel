\doxysubsection{Detailed Description}
Match timer with phase-\/aware time tracking. 

Manages elapsed time for different game phases (Pre\+Game, First\+Half, Half\+Time, Second\+Half, Post\+Game). Tracks elapsed time independently for each half and emits updates every second. Automatically stops at 45-\/minute mark for halves or based on phase-\/specific timing.

Features\+:
\begin{DoxyItemize}
\item Phase-\/aware time tracking for match states
\item Independent timing for First\+Half and Second\+Half
\item Automatic timeout emission at phase end
\item Per-\/second time update signals for display
\item Play/pause capability with restart functionality
\item Total elapsed time and phase-\/specific time retrieval
\end{DoxyItemize}
