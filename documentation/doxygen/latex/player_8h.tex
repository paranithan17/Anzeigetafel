\doxysubsection{Detailed Description}
Player data model for roster management. 

Represents a single player with identification number and name. Used by team rosters (team) for tracking player information. Players are managed through shared pointers for efficient memory management and automatic cleanup.

Features\+:
\begin{DoxyItemize}
\item Player number and name storage
\item Getter and setter methods for player attributes
\item Lightweight data model for roster management
