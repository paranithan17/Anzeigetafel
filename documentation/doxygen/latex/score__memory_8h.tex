\doxysubsection{Detailed Description}
Score and goal event management. 

Manages all scoring information including goal events, player information, and score calculation for both teams. Stores complete match score history and provides methods to add/remove goals and retrieve current scores. Emits signals when goals are updated.

Features\+:
\begin{DoxyItemize}
\item \doxylink{struct_goal}{Goal} event storage with player details and timestamps
\item Home and away team score tracking
\item Own goal detection and handling
\item Score reset and goal removal with undo capability
\item Signal-\/based notifications for score changes
\item Complete match history for logging and review
\end{DoxyItemize}

Data Structure\+: Maintains a QList of Goal\+Event objects, each containing player number, name, team designation, timestamp, and own goal flag.
