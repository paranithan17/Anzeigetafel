\doxysubsection{Detailed Description}
Central controller for match logic and state management. 

The \doxylink{classmatch__controller}{match\+\_\+controller} is the business logic layer (Model in MVC pattern) that manages all match-\/related operations including team rosters, scoring, timer control, and state transitions. All user interactions from the GUI (\doxylink{classcontroll__window}{controll\+\_\+window}) or web interface are delegated to this controller, which processes them and emits signals for view updates.

Features\+:
\begin{DoxyItemize}
\item Team roster management (add/remove players, CSV import)
\item \doxylink{struct_goal}{Goal} logging with validation and emblem management
\item Match timer control (start, stop, restart) with phase transitions
\item Match state machine (Pre\+Game → First\+Half → Half\+Time → Second\+Half → Post\+Game)
\item Data persistence through \doxylink{classscore__memory}{score\+\_\+memory} and timer components
\item Signal-\/based communication for MVC pattern
\end{DoxyItemize}

Design Pattern\+: Implements Model-\/\+View-\/\+Controller (MVC) where \doxylink{classcontroll__window}{controll\+\_\+window} and future web interface are views that delegate all business logic to this controller. This enables code reuse across multiple UI implementations.
