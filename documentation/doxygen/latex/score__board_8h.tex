\doxysubsection{Detailed Description}
Scoreboard display window for live match information. 

Displays live score, match time, and goal scorer information to audience. Supports fullscreen mode, team emblems, and state-\/based content (slides for Pre\+Game/\+Half\+Time/\+Post\+Game, match stats for First\+Half/\+Second\+Half).

Features\+:
\begin{DoxyItemize}
\item Fullscreen display with frameless window.
\item Dynamic font scaling based on window size.
\item Scoreboards (team emblems, score, time, goal list).
\item Slide show for non-\/game states.
\item Double-\/click toggle to hide/show control window.
\end{DoxyItemize}
