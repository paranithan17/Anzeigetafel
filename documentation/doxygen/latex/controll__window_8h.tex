\doxysubsection{Detailed Description}
GUI Control window for match operator (View component). 

Pure presentation layer that provides the operator control interface for managing matches. Displays team rosters, score, timer, and match state. All user interactions are collected via dialogs and delegated to \doxylink{classmatch__controller}{match\+\_\+controller} for processing. This component receives updates from \doxylink{classmatch__controller}{match\+\_\+controller} through Qt signals and updates the display accordingly.

Features\+:
\begin{DoxyItemize}
\item Team roster UI with add/remove player dialogs
\item \doxylink{struct_goal}{Goal} logging dialogs with player selection and own-\/goal detection
\item Timer control buttons with state validation feedback
\item Match state selection (Pre\+Game → First\+Half → Half\+Time → Second\+Half → Post\+Game)
\item Team emblem upload and logo management
\item CSV import dialogs for batch player roster management
\item Scoreboard toggle via double-\/click feature
\item Real-\/time score and time display updates from controller
\end{DoxyItemize}

Design Pattern\+: Implements View component of MVC pattern. All business logic is delegated to \doxylink{classmatch__controller}{match\+\_\+controller}, enabling code reuse for web interfaces and other UI clients. Uses Qt signals/slots for communication with model.
